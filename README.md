# 尘起时刻（网页版）

桌游《尘起时刻》的网页实现（TypeScript + Vite + 原生 DOM/CSS）。
引擎（`src/core/`）零 UI 依赖，界面（`src/ui/`）单向调用引擎；支持本地双人、在线联机与单人挑战。

> 本项目已获桌游《尘起时刻》作者 **Lambda** 的口头授权，为非商业同人实现。

- 主创：**无言的双子龙**
- 开发方式：OpenCode + DeepSeek V4.1 Flash 协作开发

## 游戏模式

模式：预设 / 构筑 / 轮选（支持本地左右互搏与在线联机）；挑战为单人对抗「昔日传奇」。
2v2 团队模式已列入长期计划，尚未实现。

## 本地开发

要求：**Node.js ≥ 20**。

```bash
npm ci          # 安装依赖（package-lock.json）
npm run dev     # 开发服务器 http://localhost:5173/
npm test        # 运行全部测试（vitest）
npm run typecheck
npm run build   # tsc + vite build → dist/
```

联机自测：

```bash
npm run relay   # 本机中继，默认 8787
# 浏览器打开：http://localhost:5173/?server=ws://localhost:8787
```

（同机双标签无需中继：直接开两个标签即可。）

## 打包与部署

| 产物 | 命令 | 说明 |
|---|---|---|
| 本地试玩包 | `node scripts/build-delivery.mjs` | 单文件 `index.html`（资源内联）+ 卡图目录；产物 `尘起时刻-试玩.zip` |
| 联机部署包 | `node deploy/pack.mjs` | 含 `www/`、中继、`deploy/` 配置与说明；产物 `delivery/尘起时刻-联机部署.zip` |

部署文档：

- **从源码构建与更新**（推荐给服务器管理员）：[`deploy/README-源码部署.md`](deploy/README-源码部署.md)
- **部署包安装与运维**：[`deploy/README-部署.md`](deploy/README-部署.md)

> 必须部署在**域名根路径**（字体/资源使用根路径）；联机由 nginx 将 `/ws` 反代到本机中继。

## 玩家须知

- 浏览器：Chrome / Edge / Firefox / Safari 近两年版本。
- 触屏操作：战斗界面**单击卡图看技能**；选择界面**长按卡图看技能**（单击是选定）。
- 联机：双方必须使用**同一版本**（更新后请全员硬刷新）；支持断线重连、旁观与 4 位数字房间密码。
- 手机：本作没有专门适配手机界面；可在「设置 → 整屏缩放」把界面调到合适大小（手动 10%–100%）。

## 数据与隐私

- 无账号系统；身份 key 保存在本机浏览器（清缓存/换浏览器视为换人）。
- 对局状态只在双方浏览器与中继内存中，**不落库**；无回放/存档。
- 聊天经中继转发（明文），朋友局适用。

## 目录结构

```

```
